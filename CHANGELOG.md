# Change record

## 0.3.0 - 2026-10-03

The release includes the native Windows sidebar and verified terminal focus.
It includes provider metadata hooks, account quota state, public output, and persistent notes.
It adds a current user start at sign-in option in Settings.
It adds the Windows installer, portable ZIP, wheel, source package, and release records.
It adds frozen helper commands for installation without Python.
It corrects event ordering at datetime timestamp precision.
It prevents an oversized log record from blocking later state events.
It validates configuration field types and values.
It adds locked dependencies, code format checks, coverage reports, and release CI.
It rewrites maintained English documentation under ASD-STE100 Issue 9 rules.
It records the adversarial review and its evidence limits.
